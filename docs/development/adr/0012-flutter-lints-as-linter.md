# 0012 — Use flutter_lints (default) as the linter

**Status:** Accepted, 2026-08-10

## Context

At the start of the project, a linter configuration had to be chosen.

## Decision

Use `flutter_lints` (default) as the linter.

## Consequences

The default ruleset is gentle (`Sanft`) and sufficient (`ausreichend`); it can be tightened later (`kann später verschärft werden`).
